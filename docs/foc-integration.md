# FOC 연결 지점

기준 소스는 BL4270E1K용 STM32G431 프로젝트의 2026-10-03 스냅샷입니다. 생성 프로젝트와 필요한 ST Motor Control SDK 6.4.2 소스는 저장소에 포함했습니다. `foc/STM32CubeIDE`를 가져와 빌드합니다. `foc/Inc`의 파라미터는 당시 설정이므로 다른 모터·전력 보드에 그대로 적용하지 않습니다.

아래 호출은 포함된 프로젝트에 이미 연결돼 있습니다. 다른 프로젝트로 옮길 때의 참고 사항입니다.

1. 생성 프로젝트 루트에 `App` 폴더를 배치하고 빌드 소스에 포함합니다. 상대 include는 `App`과 `Inc`가 같은 루트에 있는 구조를 전제로 합니다.
2. MCSDK 초기화 후 `FFB_App_Init()`을 한 번 호출합니다.
3. 메인 반복문에서 `FFB_App_Poll()`을 호출합니다.
4. MCSDK 중주파 작업 후크에서 `FFB_App_MediumFrequencyHook()`을 1 ms 기준으로 호출합니다. 코드 내부의 변화율 계산은 이 간격을 사용합니다.
5. USART1 IRQ와 HAL UART 콜백의 중복 정의 여부를 확인합니다. App 소스에 IRQ·콜백 구현이 있습니다.

## 설정

- USART1 PB6/PB7, 115200 / 8N1. USART2 MCP 경로와 분리
- TIM2 엔코더 카운터는 MCSDK가 소유하고 App은 읽기만 수행
- 모터 1회전 4000 counts, 릴 1회전 12000 counts
- 텔레메트리 주기 50 ms
- App Iq 상한 3.0 A. MCSDK 설정 상한과는 별도
- 정상 RUN 상태와 fault 없음이 확인될 때 전류 지령 적용
- 자동 모터 START는 구현하지 않음

FOC 소스에는 초기 호스트 모사 계층에 없는 signed 명령과 카운터 정렬 보정이 추가돼 있습니다. 두 버전의 App 폴더를 섞어 사용하지 않습니다. 포함된 생성 코드와 라이브러리로 Debug/Release 컴파일·링크를 확인했습니다. 실제 모터 구동과 호출 주기 계측은 이번 빌드 검증에 포함되지 않습니다.
